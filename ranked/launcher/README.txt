Shattered Paradise - Ranked build {VERSION}
============================================

1. Install the .NET 6 runtime (only needed once)
   Download ".NET Desktop Runtime 6.0" (x64) from
   https://dotnet.microsoft.com/download/dotnet/6.0
   play.cmd tells you if it is missing.

2. Unzip this archive anywhere (e.g. your Desktop or C:\Games).
   Keep the folder structure as it is.

3. Double-click play.cmd to start the game.

4. On the first start the game asks for the Tiberian Sun content.
   Use the in-game installer to download it (one-time, needs internet).

5. Click "Ranked" in the main menu to log in and find a match.
   Both players must use the same version of this build.

Crash logs: %APPDATA%\OpenRA\Logs

Version: {VERSION}
